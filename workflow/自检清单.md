# 自检清单

---

## A · 物理（任何一条不过 = 返工）

- [ ] **A1** 本章每个数字都能追溯到 `docs/02-物理正典` 的表或公式。列出：数字 → 出处。
- [ ] **A2** 本章的轨道日期与距离已标注，且单程光时 = 距离(AU) × 8.317 成立。
- [ ] **A3** 每一处跨星球的"知道/反应"，滞后 ≥ 一个单程光时。列出每一处及其滞后量。
- [ ] **A4** 没有出现被废止的设定（查 `docs/09` 第一节的"废止版本"栏——特别注意 0.1c、红外总量测算、海洋升温、熵债/帝国残留）。
- [ ] **A5** 激光只打了不会机动的东西；帆弹的助推、飞行、当量三个数与正典一致。

## B · 逻辑

- [ ] **B1** 本章没有反派。每个角色的行为在他自己的信息条件下是最优的。逐个角色说明。
- [ ] **B2** 本章没有巧合。每个转折都能追到一条已建立的物理或制度约束。
- [ ] **B3** 没有角色知道 `docs/08` 信息状态矩阵不允许他知道的事。
- [ ] **B4** 两台 AI 没有读心、没有预知、没有越过内核、没有提议拆除人类否决权。

## C · 文体

- [ ] **C1** 一章一个 POV，中途没切（文献章除外）。
- [ ] **C2** 没有超过 200 字的连续解释；每次解释都由一个有动机的人说给一个有理由听的人。
- [ ] **C3** 修辞配额：本章"漂亮句子" ≤ 1 处，且它不解释自己（后面没有跟着一句阐释）。引用该句。
- [ ] **C4** 章末最后一句是一个动作 / 一个数字 / 一个物件，不是总结。引用该句。
- [ ] **C5** 开头不是天气、心情或回忆。引用首句。
- [ ] **C6** AI 的所有输出都是概率/区间/证明对象/日志引用格式，没有抒情。
- [ ] **C7** 形容词审计：搜索"浩瀚""无垠""震撼""仿佛""似乎""不禁"，全部为 0。

## D · 结构

- [ ] **D1** 本章展示了至少一个新技术约束，或一个已知约束的新后果。写出是哪个。
- [ ] **D2** 若大纲标注本章含指定名场面（查 `docs/06`），已落地，且执行要点被遵守。
- [ ] **D3** 本章长度符合规格（实景 4000–7000 / 文献 1500–3000 / 实时按分钟）。
- [ ] **D4** 台账已回写（轨道日历 + 信息状态矩阵 + 进度表）。
