# 自检清单

> 每章交稿前逐条过（八步循环第 05 步）。**在稿末附结果，每条要给证据，不许只写"通过"。**
>
> **严重度分级**（每条后的方括号是该条默认等级；实际问题可升不可降）：
> - **S1** 设定、动机、主线或现实逻辑错误 —— **必须清零，否则不得标记完成**
> - **S2** 明显损害节奏、读感和追读 —— **必须清零**
> - **S3** 局部表达问题 —— 交稿前尽量清零，残留的列明
>
> 全部通过时，报告格式与旧版一致（逐条 ✓ + 证据）；有问题时按 S 级列问题清单。

- [ ] **B2** 本章没有巧合。每个转折都能追到一条已建立的物理或制度约束。【S1】

- [ ] **B4** 两台 AI 没有读心、没有预知、没有越过检验器、没有提议拆除人类否决权。违章只出现在公开回执里，"我判定"只出现在回执第三行。【S1】

- [ ] **C2** 没有超过 200 字的连续解释；每次解释都由一个有动机的人说给一个有理由听的人。【S2】
- [ ] **C3** 修辞配额：本章"漂亮句子" ≤ 1 处，且它不解释自己（后面没有跟着一句阐释）。引用该句。【S3】
- [ ] **C4** 章末最后一句是一个动作 / 一个数字 / 一个物件，不是总结。引用该句。【S2】
- [ ] **C5** 开头不是天气、心情或回忆。引用首句。【S2】
