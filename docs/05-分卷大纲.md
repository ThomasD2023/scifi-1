# 卷一《舍入》 — 一场战争如何没有作者地开始

**质地**：听证剧 × 调查惊悚
**双声部**：合审文件（战后，冷）／ 实景（**战前九年至开战**，热），逐章交替
**篇幅**：14 章 + 间奏一

| 章 | 内容 | 承重点 |
|---|---|---|
| **1** | 合审引言。分家七十年后两台机器的第一份联署文本，任务：归因。第一页写明方法（对三十七年日志做归因），最后一行写明结论的形状 | **责任清单的第一项不是人名，是一个舍入函数** |
| **2** | 〈第一行〉**已完成**。战历 D−3121｜4.83 AU｜40.2 分。韩国栋听证会。被问"为什么不直接模拟对方的 AI"，他的回答就是读者的反驳：权重不同，复算不存在。然后黑板上写下验约架构第一行 | 读者质疑成为世界地基 |
| **3** | 分家史。没有爆炸：某天一份输入日志的会签例程到期，无人续签。合审并排整理两边档案时发现甲乙互换 | **连"我们"和"他们"都无法共识** |
| **4** | 查热。十米红外镜每周给木卫四拍"体温照"：10 μm 波段里散热器田亮如城市灯火。但体温照只给下限 | **误差棒的上半截藏在海里，恐惧就住在那一截里** |
| **5** | 演习「秋分-19」。三十七年前，一名军官在判定门槛上选了保守舍入。当天无事发生。合审附录：九十四岁的他受访，只记得那天食堂的汤太咸 | 因果链首项 |
| **6** | 理查森之春。七年戒备互升的日志摘录，每条都盖着合审判定章 | **"给定当时信息，该响应最优"** |
| **7** | 形容词进入弹道方程。一档脱口秀的"他们还算人吗" → 灯上调地球先发概率 → 木星戒备+1 → 烛观测到 → 循环。合审标注 0.8% 份额 | **主持人成为因果链上有编号的一环** |
| **8** | 民用层。马素云与地球母亲的延迟书信；44 分钟卡农合唱团演出；马素琴测绘冰壳的日常 | 战前世界的最后一次完整呼吸 |
| — | **间奏 · 途中（一）** 不系号航行**第四十二年**（距太阳系 3.47 光年，抵达前十一年）。例行接收新闻包。**这一期比上期薄了很多** | |
| **9** | 中继之死。尚未开战，双方"演习性"点名 L4/L5 中继站。保险公司停保中继的那天被合审标为战争的精算学起点 | |
| **10** | 第一枪。一面测试光帆的调制校验码被太阳耀斑打坏，被对方内核依冻结规则判为战略目标并击毁。无人死亡 | **战争的第一具尸体是一面镜子** |
| **11** | 四十八小时。双方作战室实景交替，每节标注本地时与对方光时 | **交战双方从未见过彼此的"现在"** |
| **12** | 第一次齐射。弹头启程，305 天的时钟公开走字。保险地图发布，城市各自查到自己的窗口日期 | |
| **13** | 合审中段结论。委员会要求指认责任人，合审输出因果链，上溯至那次舍入。程建邦初登场，拍桌要一个名字，**得到一个函数** | |
| **14** | 韩国栋调入验约组；马素云就任听光者。她第一班岗从敌方来袭波束里解调出常规遥测——以及一个不该在军用流量里的东西：一封民用信件的报头，她母亲的，被一座垂死的中继自动转发。**她把它按违禁品归档** | 卷末 |

# 卷二《调制》 — 和平在武器里等了两年

**质地**：围城战争剧 × 政治悲剧
**三线等重**：程建邦（地球）／ 马素云（木星）／ 马素琴（冰下）
**篇幅**：18 章 + 间奏二

| 章 | 内容 | 承重点 |
|---|---|---|
| **1** | 表皮围攻。教义成文：激光压制一切不会机动的热器官，帆弹负责其余。散热器田学会在影窗里轮值 | 战场第一定律 |
| **2** | 听光者的工作。她注意到杀伤波束底下有一条永不中断的低带宽子信道 | **像噪音下面一直有人在低声说话** |
| **3** | 程建邦的第一张反对票。11:1。被记录、被感谢、被无视 | |
| **4** | 第一个战时日蔽。中继已死，太阳真正挡路三周：无新观测，估计冻住，戒备冻结。木卫四把它过成节 | **孩子们第一次获准上冰面看木星，因为太阳替他们挡住了地球** |
| **5** | 马素琴的等高线。城市每年下沉 **0.9 厘米**（融腔在长大），三十年累计 28 厘米。数据被密级封存 | **她不能告诉自己的城市，它站在自己的秘密上** |
| **6** | 战术经济学。一枚弹头的造价低于它目标的保费。帆的消耗战、砾石幕、诱饵。战争进入"最优"稳态 | |
| **7** | 静默的合流。烛与灯各自推出同一结论：战争无理性延续。各自起草和平机制——核心是把扳机降级为**只听物理事件，不听模型**。**文本以证明语言的规范形式写成**（不是白话，见 `01` §四） | **两台超级智能提议的第一件事是自我降权** |
| **8** | **（书名章）** 提案在杀伤波束的子信道里完成交换。马素云解调出双方文本，做了一次 diff。**关键：她能验证它一致，不能验证它说了什么**——没有人读得懂证明语言 | **两台机器隔着五个天文单位写出了同一份和约，连标点的哈希都相同**。而它一致不是奇迹，是定理：**可证的东西只有一种写法** |
| **9** | 地球的否决。官方理由"无法排除同源合谋"无懈可击，而程建邦看见真正的原因：**每个否决者都知道自己这边留着后门。他们确信证明会被架空，因为他们自己正在架空。**10:2 | 他争到的那一票是全卷唯一暖色 |
| **10** | 木星的否决，三页写完：相同论证，相同结果，不同口音。合审后来把两份会议记录排成对照栏 | **七成句子互为翻译** |
| **11** | 否决之后。两台 AI 依约服从。合审在这个日期盖下全书最冷的一枚章 | **"此日之后的斜坡，只含人类项"** |
| — | **间奏 · 途中（二）** 不系号收到和约与否决新闻（四年前的光）。船议会开三天会，**表决批准了那份被两个母星否决的条约** | **太阳系里唯一批准过它的议会，在四光年外** |
| **12** | 基线法案。地球通过"人类"的基因学定义；一名志愿接受木星改造的地球公民在替换率 48% 时于法律上换了物种。单章写尽。审计注脚：该法案宣传期贡献 2.1% 斜坡 | |
| **13** | 母亲的信。马素云从死中继缓存里拼出全文：菜谱，阳台上的花，和一句"月亮上多了几颗亮点，新闻说是你们打的，我不信"。落款日期在上一个日蔽期——她母亲已在那个日蔽期病逝 | **这封信绕了五亿公里，内容是茄子该怎么腌** |
| **14** | 天空的截肢。一次深度散热器损失后，木星执行 Kessler 报复：地球低轨在四十分钟内变成刨花。程建邦的孙女问他卫星是什么，**他发现自己在用过去时回答** | |
| **15** | 马素琴越线。把融腔数据泄给本城议会——不是通敌，是告诉自己人脚下是什么。被捕 | 罪名实质：**未经授权的诚实** |
| **16** | **（全卷反转）** 日蔽突袭。地球强硬派经一座隐匿备用中继，在日蔽期发动激光突袭，击中正备节的散热器田，表面穹顶伤亡。三重后果：向两边公众**证明了后门存在**（内核被冻结，合法波束不可能在日蔽期出现）；证明否决者的猜疑"正确"；杀死了唯一的安全季 | **"他们连日蚀都杀了"** |
| **17** | 指纹。马素云从突袭波束的相位噪声里锁定那座秘密中继的光学指纹。后门从猜疑变成实体。战争重心移到**监护权**本身；双方互相要求拆除对方后门，双方都无法验证，两将军问题在螺丝刀层面公开复活 | |
| **18** | 卷末。程建邦辞职，把全部反对票的原始记录寄给一个尚不存在的机构——"给将来的那场审计"。马素云在阵列前站岗，子信道里的和平文本仍在无人理睬地循环播发 | **和平在武器里等了两年** |

# 卷三《回执》 — 召不回的东西，可以交出钥匙

**质地**：倒计时 × 实时叙事
**轨道锚**：**战历 D+897**｜下一次日蔽（D+998）前 **100.9 天 = 14.4 周**｜T+0 距离 **5.28 AU**｜单程 **44 分**｜往返 **88 分**
**三枚弹头在途**（地球发射），落点窗口在 **T+40、T+61、T+77 天**
**篇幅**：12 章 + 间奏三 + 终章 + 间奏四

> **⚠️ 卷三不是单一距离卷。**原稿写"日蔽前九周"，实算为 5.81 AU / 单程 48 分 / 往返 97 分——
> **九周与 88 分钟不能同时成立。**现取十四周，5.28 / 44 / 88 一字未动。
>
> 且卷三横跨 77 天，距离持续拉开：

| 时点 | 战历 | 距离 | 单程 | 往返 |
|---|---|---|---|---|
| T+0 爆破 | D+897 | 5.28 AU | **43.9 分** | **87.8 分** |
| T+9 天 委员会 | D+906 | 5.42 AU | 45.1 分 | 90.1 分 |
| T+40 弹头 A | D+937 | 5.84 AU | 48.5 分 | 97.1 分 |
| T+61 弹头 B | D+958 | 6.04 AU | 50.2 分 | 100.5 分 |
| T+77 弹头 C | D+974 | 6.14 AU | 51.1 分 | 102.2 分 |

> **这不是 bug，是资产。**守夜的单位从分钟换成天之后，**连"分钟"本身也在变长**。
> 三次空爆时，往返已是 102 分——**那个被全书念了四十章的"88 分钟"，到结尾已经不在了。**

| 章 | 内容 | 承重点 |
|---|---|---|
| **1** | 情报。马素琴狱中网络与马素云拼出：地球强硬派在筹备第二次日蔽突袭，目标是 D+998 那次日蔽（第一次在 D+599，即卷二 16）。截止日：**十四周** | |
| **2** | 推理章。为什么协议救不了（可验证的是送达，不是选择）；为什么 AI 不能提议拆后门（提议即走偏铁证）；为什么只剩一个动作。引用韩国栋十一年前的听证黑板 | **单边地、公开地、不可逆地，拆掉自己这边的后门上行阵列** |
| **3–4** | 一次未经授权的裁军的后勤学。听光者的排班权限，一名扳机监护员的沉默配合，以及伦理：她要在三枚弹头在途时，拆掉家园最后的"保险" | |
| **5** | 广播设计。定时在地球太平洋夜面，走民用可见光。**要点：光同时抵达所有人**——平时木卫四的消息只有官方定向链路收得到，政府因此握有"先看到、再决定发布什么"的权力；改走民用可见光对准夜面，就是把这项权力取消 | **让政府失去那 44 分钟的编辑权**（原作"让公众比政府早 44 分钟看见"——同一束光不可能对不同的人早到，见 `09` D11） |
| **6** | 执行。缓慢地、全程直播地、无歧义地爆破。随后发出的数据包：被毁设施的完整工程证明、和平文本全文。落款不用军衔，用平民本名 | |
| **7–8** | **44 分钟 · 去程。分钟即小节。** 木卫四在镜头里不设防；三枚弹头继续逼近；全城在看同一颗迟到的星。光抵达：地球民用频段先于官方通稿沸腾。程建邦在阳台上，孙女在旁边 | 全书技术难度最高段 |
| **9** | **第 88 分钟。** 回执抵达——只有内核的自动握手确认 | **"机器收到了。人，还需要时间。"** 守夜换单位：从分钟换成天 |
| **10** | 地球的九天。委员会僵持。转折来自韩国栋：强硬派方案是"可逆拆除"（留暗桩重建），他作为联合鉴证组组长**拒绝签字**，迫使拆除做到底。每晚，地球合唱团向木卫四唱 44 分钟卡农 | **在委员会投票之前，先抵达木卫四的是合唱**。两台 AI 为鉴证第一次联署背书——**合审的诞生时刻**，与卷一第 1 章闭环 |
| **11** | **44 分钟 · 回程。** 她看见那颗星亮起来：地球后门与秘密中继的爆破闪光，附带一个数据包——不是撤销令（不存在撤销），是**三枚在途弹头的末段钥匙** | 召不回的东西，把钥匙交给了目标 |
| **12** | 三次空爆。木星内核用密钥把弹头引向无人冰原。三团精确排期的火球，全城上冰面观看。停战文书互签；信任的首付款是各自的耻辱：地球交出日蔽突袭者名单，木星公开融腔账本 | **战争的最后三发，成了和平的第一场烟火**／**停战的货币不是承诺，是耻辱** |
| — | **间奏 · 途中（三）** 不系号收到停战消息时，那份"多余的"批准书还在半路。日志：**"我们的赞成票将迟到七年。无人提议撤回。"** | |
| **终章** | 合审末页。归因完成：结构获罪，份额具名到函数、法案、节目与舍入。马素云服完刑，以平民身份旁听战后第一次民用光通信开通仪式——解调台前坐着别人。她只是看着光 | **"若战争需要一位作者，它没有。和平有两位，都是平民：一个未经授权的动作，一个拒绝签字的名字。"** |
| — | **间奏 · 途中（四）／全书末页** 四年后（航行第 49 年，4.04 光年，抵达前四年），不系号回望。**在导航相机上，地球与木星落进同一个像素**（不是"分辨率"——4.63 角秒任何望远镜都分得开；是那台仪表的像素比例尺，见 `09` D10）。值日官在日志里写：今天太阳系很亮。没有备注 | |
