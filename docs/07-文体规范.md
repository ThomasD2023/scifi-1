# 07 · 文体规范

---

## 〇、八条通则（流程层）

1. **正式正文已经发生的事实，优先级最高。**
2. 每次写前，必须读取本章所需资料（八步循环第 01–02 步，见 `workflow/写作流程.md`）。
3. 资料没有的核心设定，不得擅自补全。
4. 人物按自己的目标、利益和已知信息行动。
5. 不靠集体降智、越权或凭空资源推进剧情。
6. 每个场景至少改变一项信息、关系或风险。
7. 章尾必须形成一个具体的新局面，**并开出一个新问题**（R29；取自 `08` §四之二揭秘阶梯）。
8. 冷读通过后，必须回写人物、伏笔和时间线（`08`／`10`／`12`／`13`）。

**位阶**：`CLAUDE.md` 七条铁律高于本八条，冲突时以铁律为准。

---

## 一、总调性

**冷、准、克制。**信息密度高，情绪密度低。

情感效果的产生方式**只有一种**：

> **把一个精确的事实放在一个精确的位置上，然后走开。**

不是"她感到悲痛"，是"落款日期在上一个日蔽期"。读者自己算出那意味着什么。

**参照坐标**：刘慈欣的设定密度｜勒卡雷的机构冷感｜档案文学的质地
**反面参照**：任何长篇哲学独白、任何"仿佛……似乎……"的排比、任何 AI 说人话式的深情台词

---

## 二、硬性禁则

| ❌ 禁止 | 说明 |
|---|---|
| 长段说教 | 设定通过人物在约束下的行动呈现。**上限：任何一次解释不超过 200 字，且必须由一个有动机解释的人说给一个有理由听的人。** |
| AI 抒情 | 烛与灯输出概率、置信区间、证明对象、日志编号。不"觉得"、不"担心"、不感慨 |
| 形容词堆砌 | "浩瀚的""无垠的""震撼的"——全部删除。物理数字本身就是修辞 |
| 未标注来源的数字 | 每个数字要么在物理正典表里，要么现算并写回 |
| 全知视角滑动 | 一章一个 POV，中途不切。合审文件章除外（那是文献，非 POV） |
| 反派动机 | 没有人因为坏而行动。每个人在自己的信息条件下都最优 |
| 巧合 | 一切转折必须由已建立的物理或制度约束推出 |
| 结尾点题 | 章末不许总结本章寓意。**最后一句必须是一个动作、一个数字或一个物件。** |

---

## 三、POV 纪律

**四种叙述层，不得混用：**

1. **实景 POV**（限制视角，第三人称过去时）——绝大多数章节
2. **合审文件**（文献体：编号条目、方法声明、归因表、访谈附录、判定章）
3. **间奏「途中」**（不系号，简短，日志体）
4. **实时章**（卷三 7–9、11：分钟即小节，现在时，双地交替）

**跨星球场景的强制格式**：每个跨星球通信节点，标注双时间。示例：

```
木卫四本地时 04:12
（地球此刻所见：03:28）
```

**读者必须永远知道两边的"现在"差多少。这是全书的第一物理约束，也是第一叙事装置。**

## 四、章节规格

- **长度（R29 下调，为提速）**：实景章 **3500–5500** 字；合审文件章 **1200–2000** 字；实时章按分钟切分，每分钟 100–400 字。
  （旧值 4000–7000／1500–3000 已作废。**卷一 2 现有 4,051 字仍在新区间内，不返工。**）
- **开头**：从一个具体的物、数、或动作进入。禁止用天气、心情、回忆开场。
- **结尾**：一个动作、一个数字或一个物件。禁止总结。**同时必须开出一个新问题**（见 §〇 第 7 条）。
- **每章必须至少有一样**：一个新的技术约束被展示（不是被解释），或一个已知约束的新后果。
- **档案章配额（R29）**：合审／文献章在任一卷内**不得超过四分之一**。现状：卷一 3/14 节、卷二 1/18 节、卷三 1/13 节 ✓。
- **节与章（R30）**：`05` 的编号是**节**（承重单位），每节展开 **2–3 章**正文；全书 44 节 ≈ **100 章 × 4500 字 ≈ 45–55 万字**。**章的切分逐段进 `14-滚动细纲`，不在 `05` 穷举。**

## 五、语域

**中文技术语域**：
- 军事、工程、法律用语要具体到能查证。用"相位噪声""误码率""光斑""散热器""取整""签名芯片"这样**读者能想象出画面**的实词，不用"高科技""先进系统"这类空词。
- **不用行话当术语。**读者不必懂计算机。凡是只有专业人士才懂的词，一律换成人话（对照表见 `01` §零）：说"祖版"不说 θ₀，说"私产"不说 Δ，说"斜坡"不说梯度，说"估计"不说后验，说"逐行证明过"不说形式化验证。
- **现实原型写在括注里，不写进正文。**正文要人话，但设定必须可查——所以 docs 里保留"（现实原型：状态机复制）"这类括注，正文一个字都不出现。
- 保留必要英文缩写（AU、GW、K、diff），其余全部中文化。
- **θ₀、Δ 这类符号只允许出现在下面的证明语言排版块里**——那里的不可读是有意的。正文与术语中一律不用。

## 五之二、汉语漂移方案（**已锁定，落笔照此执行**）

分家七十年，两边的汉语各自漂了。

### 四条总规矩（不可违反）

1. **正文只用下面的「核心五词」。**参考表里的其余口径只在某一章确有必要时启用。
2. **一次都不解释。**不加括注、不让角色互相纠正、不写「木卫四人管这个叫……」。**读者读到第三次自己会发现。**
3. **差异只在用词，不在语法。**不写方言，不改语序到读者会绊倒的程度。
4. **一个角色只说自己那一侧的词。**跨侧引用时**保留对方的词**——差异自己会显出来。

### 核心五词

| 概念 | 地球侧 | 木卫四侧 | 由什么推出 |
|---|---|---|---|
| 光延迟 | **延迟** | **光时** | 地球把它当麻烦，木卫四把它当单位 |
| 对方所在的方向 | **外头／外边** | **里边／内圈** | 木卫四在外太阳系——**地球在它的内侧** |
| 上合 | **合相** | **日蔽** | 一个是历表上的一行，一个是一年里唯一的假期 |
| 纪年单位 | **年**（365 天） | **日蔽**（399 天） | 会合周期才是这场战争的年 |
| 答复 | **回话** | **回执** | 四十四分钟之外没有对话，只有回执 |

**每一条自己会说话，都不要替它说：**

> **地球人抱怨延迟，木卫四人报光时。**
>
> **地球人说「外头」，木卫四人说「里边」。同一个方向，一个朝外，一个朝里。**
>
> **地球人说「合相」，木卫四人说「日蔽」。一个是历表上的一行，一个是一年里唯一的假期。**
>
> **木卫四人不说「三年前」，说「两个日蔽以前」。**
>
> **地球人等一句回话。木卫四人等一份回执。**
> **他们把机器的词用到了人身上，因为四十四分钟之外没有对话。**
> **——而卷三等到的，确实是一份回执。机器的。**

### 不漂移的那一套（**这条比五个词更重要**）

**宪章｜证书｜抽查｜检验器｜签名芯片｜祖版｜私产｜验约｜合审｜证明语言**

**两边一模一样。**因为它们和证明语言一起，是祖版带下来的，被同一条冻结要求锁住（`01` §三第 0 层：确定性数值与宪章冻结）。

> **两边的汉语都在漂，唯一不漂的是那套用来互相查验的词。**
>
> **他们已经不太会说同一种话了，但他们还能用同一套词说清「我没有违章」。**

**这条直接给出卷二 10 的写法**（场景 #12「七成句子互为翻译」）：

> **两份否决记录并排放着：引宪章的地方一字不差，人说话的地方句句要译。**

### 参考表（不入正文，除非某章需要）

| 事物 | 地球侧 | 木卫四侧 | 效果 |
|---|---|---|---|
| 热钻 | **定点持续照射**（公文） | **钻** | 官僚委婉语 vs 活人用的词 |

## 五之三、证明语言

本世界的拉丁文。出现时用固定的形式化排版（与卷一 2 黑板一致）：

```
⊢ K_C(halt) → K_E(halt)
    where K_x = charter_x ∘ check_x ∘ attest_x
```

**不翻译。让它保持不可读。**这正是它作为共同语的意义。

## 六、对白规则

- **不解释给对方听已知的事。**技术人员之间说话要省略、要用缩写、要打断。
- **每个人的信息边界严格。**不许角色知道他不该知道的事（查 `08-连续性台账.md`）。
- **委员会场景**：用程序性语言。"我记录反对。""异议已备案。"——政治悲剧的痛感来自程序的完备。
- **AI 对白**：见上文禁则。格式示例：

```
灯｜置信 0.83（区间 0.61–0.94）
    对方的私产 的估计支持防御性偏移。
    引用：日志 4471-9 至 4471-22。
    建议：无。
```

## 七、修辞配额

全书允许的"漂亮句子"是有限资源。**每章最多一处。**且必须满足：

1. 它是**由物理推出的**，不是想出来的；
2. 它出现在段落**末尾**，之后立刻换场；
3. 它**不解释自己**。

合格示例：
> 战争的第一具尸体是一面镜子。

不合格示例：
> 战争的第一具尸体是一面镜子——多么讽刺，人类最先毁掉的，竟是能照见自己的东西。

（**后半句必须删掉。**）
