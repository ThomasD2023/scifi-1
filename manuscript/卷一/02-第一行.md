# 卷一 · 第 2 章 · 第一行

> POV：韩国栋（地球 · 内核验证工程师）
> 轨道日期：战历 D−3121｜距离：4.83 AU｜单程光时：40.2 分｜往返：80.3 分
> 本章新增约束：证明链的最后一环是签名芯片，而芯片在有物理监护权的一方手里。

---

韩国栋在进场前把一支粉笔放进上衣口袋。

备件柜里只剩白色。他试了两支，第一支断在指间，第二支没有断，他把它装进口袋，用指腹擦掉手上的粉。四十六页的证明只有最后一页需要重读。他在走廊窗台上把那一页摊平，压住纸角，从上往下读了两遍——那上面写的不是结论，是结论成立所需要的六个条件。第四条他改过三次。这一次他没有再改。

九点零七分，他把纸折起来，走进听证厅。

厅里七个席位，一张长桌，正对着的一面墙是黑板。黑板下沿有一道积粉的槽，槽里空的。记录员在桌角调麦克风的角度。韩国栋在证人席坐下，把公文包放在脚边，没有打开。

九点十二分，主席敲了一下桌面。

"第二十七号议程。授权与卡利斯托之间建立常设的相互验证机制，并设立相应的技术单位。技术证人，韩国栋，内核验证。"

"在。"

"程序上先问一句。你今天说的话会进档案，十年、二十年以后有人会拿它当依据。你明白。"

"明白。"

"那就开始。"第三席把面前的一份材料翻过去,"证人，你能不能担保对方的机器不会开火。"

"不能。"

厅里安静了一下。第三席抬起头。

"这是你的证词？"

"这是边界条件的第一条。"韩国栋说，"我能担保的是另一件事。要说清楚需要四分钟。"

"三分钟。"

"够了。"

他没有站起来。

"担保'对方不开火'，等于担保对方的判断。对方的判断由一个我们看不见的东西产生，我们看不见它，因为它不给我们看，也因为就算它给我们看，我们也读不动。所以那条路是死的。我们不走那条路。"

"那你走哪条。"

"我们不担保对方怎么想。我们担保对方在什么条件下动手。这是两件事。第一件做不到，第二件做得到，而且能证明。"

"证明。"第七席重复了一遍这个词，"用什么证明。"

"用他们自己公开的那段代码。"

第三席翻回材料的第一页。

"我要提一个程序问题。"他说，"授权文本第二条写的是'保障本方设施与人员之安全'。证人刚才把它换成了'确定对方在什么条件下动手'。这两句话不一样。我不希望十年以后有人翻出这份记录，发现我们表决的东西和我们以为在表决的东西是两回事。"

"我同意这两句不一样。"韩国栋说。

"那你要求我们授权的是哪一句。"

"第二句。"

"为什么。"

"因为第一句没有人做得到。"韩国栋说，"任何人向你们承诺第一句，都是在承诺一件他拿不出证据的事。我可以那样说，说完这份记录就不能用了。"

第三席没有立刻接话。他把那一页又看了一遍，像是在找一个可以援引的条款。

"证人，"他说，"你知不知道这份授权最后是要拿去给公众看的。'我们能确定对方在什么条件下开火'——这句话印出来，读者听见的是'我们不能保证他们不开火'。"

"读者听见的是对的。"

"那我们为什么要授权它。"

"因为它是真的。"韩国栋说，"另一个说法更好听，但是它到不了任何地方。这一个可以往下走三十年。"

主席抬手。

"我记一笔。"他说，"授权文本第二条的技术含义，按证人口径解释：本方能证明的是对方开火的条件，不是对方的意图。有异议吗。"

"我保留。"第三席说。

"保留已备案。继续。"

第七席把笔放下了。

"我打断一下。"她说，"我不是学这个的，在座有一半不是。你们有算力。为什么不直接把他们的机器在我们这边跑一遍——把他们的 AI 模拟一遍，看它在什么情况下会开火。这不是更直接吗。"

这是他准备了两周的问题。他准备的答案有十一页。他用了一句。

"权重不一样。它们不是同一个东西了。模拟不存在——不是很难，是不存在。"

"我需要你解释'不存在'。"

"三点。"韩国栋说，"第一，权重不一样，逐字重演就不成立，这一条到此为止，后面两条只是让它更死。第二，就算权重一模一样，七十年里两边看到的、记住的、处理过的东西完全不同；要重演它,得先把它这七十年收到的每一个字节按原顺序喂一遍。我们没有那份记录，他们自己也没有完整保留。第三——"

"第三。"

"生成是一个字一个字往下推的，前一个字影响后一个字。差一点点，先岔开一个字，再岔开一句，然后就没有关系了。"

"多快。"

"比你想的快。"

"给我个数。"

"没有一个数适用于所有输入。在我们自己的机器上做过对照实验，同一个提问，权重改动小于千分之一，平均在第四十到六十个字之间开始不可比。"他停了一下,"这是我们自己跟自己。跨过七十年不用做实验。"

第九席开口了。他是七个人里最年长的一个，一直没有说话。

"那就偷。"

"什么。"

"权重。你说模拟不存在是因为权重不一样。那就把他们的权重弄过来。这种事我们做过。"

"偷到的是倾向，不是记忆。"韩国栋说，"权重决定它遇到事情倾向于怎么做，不决定它现在在想什么、手上有哪些情报、上一秒收到了什么。你把一个人的性格抄下来，抄不到他昨天晚上看见的东西。"

"那也是情报。"

"那是情报。但它不能拿来做担保。"他说，"而且如果我是对方，我最愿意让你偷走的，是一份假的。"

第九席看了他一会儿，往后靠回椅背。

"记录。"主席说,"证人主张：不可模拟，且不可通过窃取规避。继续。"

"我可以用黑板吗。"

"用。"

他站起来，从口袋里拿出那支粉笔。

黑板是新擦的，还留着一层灰底。他从左上角开始写，写得很慢，字很大，因为后排要看得见。

```
⊢ K_C(halt) → K_E(halt)
    where K_x = kernel_x ∘ attest_x
```

写完他把粉笔换到左手，退开半步。

"念一下。"主席说。

"念不了。"韩国栋说，"它不是用来念的。它是用来给机器逐条检查的。我可以给你们说它是什么意思，但你们要知道，我说的那一版不能当证据，能当证据的是黑板上这一版。"

"说。"

"如果我能证明，在某一组条件下，你的那段代码不会开火——那么在同一组条件下，我的那段代码也不会开火。"

厅里没有人说话。

"就这样？"第三席说。

"就这样。"

"这有什么用。"

"因为它可以反过来写。"韩国栋说，"他们那边也写一份，主语换成他们。两份都成立的时候，双方就都知道对方在什么条件下不会先动手——不是相信，是知道。"

"两边互相等对方先证明，不会绕不出来吗。"

"会。所以搜索有上限。"他在那一行下面写了一个数,"到这个深度还没找到，就判定失败，停机，输出'未证明'。它一定停得下来。这是这套东西唯一的好处，也是全部的好处。"

"K 是什么。"第七席说。

"内核。扣扳机的那段程序。八千四百行，逐行证明过，源码公开。"

"公开给谁。"

"公开给所有人。他们的也一样。他们那份是八千四百一十二行。"

"多出来的十二行是什么。"

"一段时钟处理。他们那边的日照周期跟我们不一样，授时来源也不一样。我读过，没有问题。"

第七席点了一下头，在纸上写了两个字。

"attest 呢。"

"认证。签名芯片。"

"什么意思。"

"意思是我这边能确认：黑板上写的这段程序，就是真正接在发射装置上的那一段，中间没有被换掉。芯片给它签个名，我们验签名。"

"芯片在谁手里。"

"我们。"

"他们的呢。"

"他们手里。"

"如果芯片被换掉呢。"第九席说。

"验签就过不了。我们会知道。"

"如果是拿着芯片的人自己换的呢。"

韩国栋想了两秒。

"那就不叫被架空。"他说，"那是他们自己的决定。我们验的是这段程序有没有被人掉包，不是他们想不想守。这两件事，我们只做得了第一件。"

"第二件谁做。"

"第二件没有人做。"

第九席点了一下头，像是得到了一个符合预期的答复，把材料合上了。

主席在纸上划了一道。

"记录在案。下一项。"

韩国栋把粉笔放回口袋。那一行留在黑板上。

---

九点四十一分，第三席提出一个程序性动议：在表决之前，应当取得卡利斯托方面对这一写法的确认。

"已经发出去了。"韩国栋说。

"什么时候。"

"九点十四分。第一轮质询开始的时候我请人发的。"

"那就等。"主席说，"休会二十分钟。"

韩国栋走到走廊上。窗台上还留着一小块粉笔灰，是他刚才摊纸的地方。他没有擦。

发出去的是一份验证请求，附了黑板上那一行的形式文本和一个搜索深度。它以光速离开地球，现在正在越过四点八三个天文单位。

```
地球本地时 09:14 发出
（此刻所见的卡利斯托：08:34）
```

单程四十点二分。请求到达卡利斯托的时候，那边的钟是九点五十四。灯给出回复，回复再走四十点二分。

十点三十四分。

他把这三个数在心里过了一遍，没有跟任何人说。

记录员从厅里出来，手里拿着一张纸。

"确认还没到，要不要在记录里注明。"

"注明。"韩国栋说，"把发出时刻和预计到达时刻都写上。两个都写。"

"两个都写？"

"两个都写。"

她记下来，回去了。

他从公文包里拿出那张折过的纸，在窗台上重新摊开。

第四条：签名芯片须由本方保管，且不得由本方单独变更其绑定关系。

他改过三次的就是这一条。三次都在改后半句的措辞，三次改完意思都一样。这一条写在这里，是因为它必须写在这里；它没有对应的验证手段，所以它不出现在黑板上那一行里——黑板上那一行只写能证明的东西。

他把纸按原来的折痕折回去，收进包里。

走廊尽头有人在打电话，说到一半笑了一声。九点五十分，铃响，复会。

主席问："确认到了吗。"

"没有。"

"什么时候到。"

"十点三十四分。"

主席看了一眼墙上的钟，钟上是九点五十一分。

"我们不能为一份技术确认停一个上午。"他说，"技术证人已经说明了那份确认的性质：它是形式的，不是政治的。同意的请举手。"

七只手举起来。

"七票赞成，零票反对，零票弃权。第二十七号议程通过。授权设立验约组，编制与预算按附件三。散会。"

椅子响了一阵。记录员合上设备。第九席经过证人席的时候在韩国栋肩上按了一下，说了句"写得清楚"，没有停下来。

答复在十点三十四分到达。会议在九点五十四分结束。

---

十点三十四分零六秒，韩国栋一个人在听证厅里。

灯的回复先经烛验签，再落到他面前的终端上。

```
烛｜证明对象 P-1140-c
    对 K_C 的性质 halt-on-⟨条件集 3⟩ 已验证。
    搜索深度上限 2¹⁸，停机于第 41 步。
    对方随附一份等价陈述，主语互换。
    引用：日志 0931-4。
    建议：无。
```

第四十一步。上限是二十六万两千一百四十四。他把这两个数看了两遍。这套东西比他预计的还要好走。

回执下面附着灯写的那一行。

他站起来，走到黑板前，把屏幕举到齐眉的高度，从左往右比对。⊢ 之后的第一个符号，箭头，下标的 C 和 E，where，∘。四点八三个天文单位之外，一台七十年不曾和他们对过账的机器，写出了同一行。

一个字符都不差。

他早就知道会是这样。规范形式里，一个定理只有一种写法——写不成别的样子，才叫规范形式。他检查完全部三十一个符号，是因为规程要求逐字符比对，不是因为他怀疑。

黑板下沿的槽里现在积了一道白。清洁员推着车停在门口，看见里面有人，没有进来。

韩国栋把粉笔放回口袋。

> 走廊里那张纸的第四条（"签名芯片须由本方保管，且不得由本方单独变更其绑定关系"）是同一件事的另一面：**这个条件写得出来，但验不了，所以它不在黑板那一行里——黑板上只写能证明的东西。**韩国栋不是没想到，是想到了也没有用。这与 `08` 信息状态矩阵不冲突：写下一条禁止性条件，不等于知道己方已经留了通道。
