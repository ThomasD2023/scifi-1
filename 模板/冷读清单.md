# 冷读清单（八步第 05 步 · E 组速查）

> **姿态：只看正文，不替作者脑补。**完整清单（A–E 全组＋证据格式）见 `workflow/自检清单.md`；本页是冷读时的独立视角卡。

## 六问

1. **这是谁？为什么现在这样做？**——动机必须在正文内可见，不靠 docs 补。【S1】
2. **他凭什么决定？资源从哪来？**——对照 `13`。【S1】
3. **人物有没有失忆、越权或写偏？**——对照既有正文与 `04` 声音栏。【S1】
4. **场景、位置和动作能否看见？**——画得出谁站在哪、手里是什么。【S2】
5. **哪里会让读者想跳读？**——指出全章最弱一段，给处置。【S2】
6. **章尾会不会让人马上追？**——末拍或倒数第二拍有未闭合向量（在途的东西／走字的钟／无人在意的错位）；末句仍守 C4。【S2】

## 分级

- **S1** 设定、动机、主线或现实逻辑错误——必须清零
- **S2** 明显损害节奏、读感和追读——必须清零
- **S3** 局部表达问题——尽量清零，残留列明

**S1、S2 未清零，不得标记完成。**判"追读"时的准绳查 `11`。
